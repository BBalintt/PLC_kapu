# PLC_kapu
Egy PLC programozási feladat megoldása.

A feladat egy kapu elkészítése volt amely rendelkezik egy fel, egy leeresztő, egy vészzleállító gombbal, két motorral, két érzékelővel a kapu tetején és alján, illetve egy időzítővel.
Két különböző megoldást készítettem az egy ST és egy LD megoldást.
